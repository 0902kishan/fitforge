About FitForge

FitForge is a modern fitness tracker built around one simple loop: plan, train, record, measure, improve.

It covers the parts that matter at the gym: a weekly plan, guided sessions with pre-filled weights and a rest timer, body-weight tracking, training history, estimated 1RM and effort per set — with no subscription, no account requirement and no telemetry.

FitForge is derived from the open-source openGym project (AGPL-3.0), keeping its dependency-light architecture: a React + Vite frontend, a single-file Node API, and a Docker Compose deployment you can run on hardware you control. Upstream copyright and third-party attribution live in NOTICE.md.

On top of that base, FitForge adds its own product layer: a violet/cyan visual identity with Inter typography, refreshed cards/tabs/sheets, updated application metadata, and — the main feature — a dedicated Goals workspace: active, completed and archived goals; strength, bodyweight, frequency and custom goal types; goal detail pages with check-ins; and a standalone strength-goal flow that takes a plain exercise name instead of routing you through the full exercise library.

Principles

  • Your data is yours. Local-first, one-file backups, no lock-in — leaving FitForge must always be one export away.
  • No telemetry, ever. If a feature needs analytics to justify itself, it doesn't ship.
  • Dependency-light. The backend is one Node file with a single dependency; the frontend is React, a router and a store. Small enough to actually audit.
  • Open source that stays open. AGPL-3.0, so every fork and every hosted version owes its code back to everyone.
